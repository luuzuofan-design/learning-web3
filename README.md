# learning-web3

面向新人的 Web3 学习仓库。目标是从 0 到 1 搭建完整的「智能合约 + 前端 DApp」学习路径，并沉淀可复用的工程结构。

## 仓库定位

这个仓库适合：

- 刚接触编程或刚接触区块链开发的新同学
- 想系统学习 Web3，而不是只会跑 demo 的开发者
- 需要一个长期积累学习笔记、代码模板、练习项目的地方

---

## 建议的整体结构（推荐逐步搭建）

当前仓库可以按下面结构逐步演进：

```txt
learning-web3/
├─ README.md                # 项目说明与学习路线
├─ docs/                    # 学习笔记、术语、架构说明
│  ├─ glossary.md           # Web3 术语表（Gas、Nonce、ABI...）
│  ├─ architecture.md       # 项目架构与模块关系
│  └─ roadmap.md            # 分阶段学习计划
├─ contracts/               # Solidity 合约代码
├─ script/ 或 scripts/      # 部署与链上交互脚本
├─ test/                    # 合约测试
├─ frontend/                # DApp 前端（如 Next.js）
├─ .env.example             # 环境变量示例
└─ package.json / foundry.toml / hardhat.config.*
```

> 说明：刚开始不需要一次性建全，建议每周增加一个目录并保证可运行。

## 新人需要先掌握的关键内容

### 1) 基础认知

- 区块链账户模型（EOA / Contract Account）
- 交易生命周期（签名、广播、打包、确认）
- Gas 与手续费
- ABI、事件（Event）、日志（Log）

### 2) Solidity 与合约安全基础

- 状态变量、函数可见性、修饰器
- 访问控制（onlyOwner / role）
- 常见风险：重入、整数溢出（旧版本）、权限误配
- 单元测试与断言思维（先测再改）

### 3) 工程化开发流程

- 本地链调试（Anvil / Hardhat Node）
- 「写合约 → 写测试 → 写部署脚本 → 前端接入」的闭环
- 环境隔离（`.env`）、多网络配置、脚本自动化

### 4) 前端 DApp 基础

- 钱包连接流程
- 读链上数据（call）与发交易（send）区别
- 交易状态展示（pending/success/fail）
- 用户体验与错误提示

## 分阶段学习建议（4 周版）

### 第 1 周：基础 + 最小合约

- 学会 Git 常用命令与分支开发
- 完成 1 个最小合约（Counter）
- 为 Counter 写测试（至少覆盖 +1、-1、边界）

### 第 2 周：标准合约与测试习惯

- 再做 1~2 个练习（TodoList、简化版 ERC20）
- 强化测试覆盖（成功路径 + 失败路径）
- 学会读交易回执和事件日志

### 第 3 周：前端接链

- 初始化前端（推荐 Next.js + TypeScript）
- 实现钱包连接
- 页面可读取 Counter 值并发起 `increment` 交易

### 第 4 周：小项目与复盘

- 做一个可展示的小项目（投票、打卡、任务上链）
- 补全 README、架构图、运行步骤
- 写复盘：踩坑、优化点、下一步目标

---

## 开发习惯建议

- 每完成一个小功能就 commit
- 每个目录都放一个「如何运行」说明
- 先保证可运行，再优化代码风格
- 对外部依赖（RPC、钱包、库版本）做记录
